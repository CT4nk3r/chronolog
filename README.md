# ChronoLog

**ChronoLog** is a fully-offline React Native (bare, no Expo) application for tracking the daily time deviation (drift) of one or more mechanical watches. Measurements taken at arbitrary intervals are normalised into a consistent **seconds-per-day drift rate** regardless of how much time has passed between readings.

---

## Features

- Track multiple watches simultaneously
- Log measurements at any time — even backdate them
- Automatic drift-rate calculation (s/day, rolling 7-day average, all-time average)
- Line chart of drift history (drawn with `react-native-svg` primitives — no charting library)
- Export data as JSON via the OS share sheet
- Import data from a JSON backup file (merge by id, duplicates skipped)
- Dark mode (follows system preference, toggleable in Settings)
- 100 % offline — zero network calls
- Full accessibility labels on every interactive element

## Setup

### 1. Clone and install

```bash
git clone https://github.com/CT4nk3r/chronolog.git
cd chronolog
npm install
```

### 2. iOS — install native pods

```bash
cd ios && pod install && cd ..
```

> **Note:** The `ios/` and `android/` native project directories are generated by the React Native CLI when you initialise a new project.  If they are absent, run:
> ```bash
> npx react-native init ChronoLog --template react-native-template-typescript
> ```
> and then copy the `src/`, `App.tsx`, `index.js`, and configuration files from this repository into the generated project.

## Building for production

### iOS — Archive

1. Open `ios/ChronoLog.xcworkspace` in Xcode.
2. Select **Product → Archive**.
3. In the Organizer, click **Distribute App**.

### Android — Release APK / AAB

```bash
cd android
./gradlew assembleRelease   # APK
./gradlew bundleRelease     # AAB (for Play Store)
```

The output is located at `android/app/build/outputs/`.

## Data model

```typescript
interface Watch {
  id: string;
  name: string;
  movementType: string;
  targetAccuracySeconds: number; // ±s/day
}

interface Measurement {
  id: string;
  watchId: string;
  timestamp: string;           // ISO 8601
  deviationSeconds: number;    // signed (+fast / -slow)
  referenceTimestamp: string;  // ISO 8601
  note: string;
}
```

### Drift rate formula

```
intervalMs    = Date.parse(B.timestamp) - Date.parse(A.timestamp)
intervalHours = intervalMs / 3_600_000
driftPerDay   = (B.deviationSeconds / intervalHours) × 24   // s/day
```
